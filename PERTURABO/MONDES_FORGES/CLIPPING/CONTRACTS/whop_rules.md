# WHOP RULES — Mécanique Content Rewards

> * STATUT : SQUELETTE — Le Warsmith doit compléter avec les chiffres exacts et seuils. *

---

## MODÈLE DE PAIEMENT

- **CPM** : payé par 1000 vues vérifiées par Whop
- **Seuil de soumission** : premier soumission dans l'heure qui suit la publication (règle ~1h)
- **Vues éligibles** : vues vérifiées par Whop (différent des vues platform)
- **Payouts** : mensuels / hebdomadaires selon le programme
- **Payouts cumulés** : jusqu'à ~$190k/mois côté Whop Clips / jusqu'à ~$664k all-time agences

Chiffres à confirmer et à compléter :
- [ ] CPM min observé : $... /1k views
- [ ] CPM max observé : $... /1k views
- [ ] Seuil de soumission : 60 min (selon source)

## TYPES DE CAMPAGNES

Voir `ARCHIVUM/knowledge_base/sites/` — types :
- **Logo distribution** : pas de vidéo source fournie, tu crées depuis assets statiques
- **Slideshow** : format diaporama
- **UGC from scratch** : tu tournes facecam/faceless d'après un script fourni
- **Repurposing** : repurpose d'une longue vidéo fournie

Le forge CLIPPING cible en priorité le mode **Repurposing** (clippe une vidéo longue). Pour les autres modes, la méthode diffère — à spec dans un futur doc.

## FACTEURS DE REJET CONNUS

> * À REMPLIR PAR LE WARSMITH *

Raisons de rejet Whop observées :
- [ ] Non-respect de la règle de soumission 1h
- [ ] Disclosure FTC absent (#ad / #sponsored)
- [ ] Contenu généré AI low quality (shadowban platform + Whop rejection)
- [ ] Vidéo non "transformative" (Reused Content policy)
- [ ] ... à enrichir

## COMPLIANCE FTC

- **Disclosure obligatoire** : `#ad` ou `#sponsored` visible dans la caption
- **Position** : début de caption (visible avant "voir plus")
- **Plateformes concernées** : TikTok, Instagram Reels, YouTube Shorts — Toutes
- **Sanction** : rejection Whop + potentiel ban platform

## STRATÉGIE CPM OPTIMISATION

> * À REMPLIR PAR LE WARSMITH *

Notes sur comment maximiser le CPM :
- Multi-plateforme (même clip → TT + Reels + Shorts + X)
- Volume (10-20 clips/jour en batch)
- Warmup comptes (voir `clipping_rules.md`)
- Tracking UTM / Bitly pour prouver les perfs et négocier meilleurs taux
