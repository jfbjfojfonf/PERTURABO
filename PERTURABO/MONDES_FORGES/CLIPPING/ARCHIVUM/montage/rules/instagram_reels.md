# 🎬 Règles de Montage — Instagram Reels

> *Le fer qui veille connaît chaque faille de la fortification.*

## Format

- **Durée** : 15-30 secondes (optimal : 15-20s)
- **Aspect ratio** : 9:16 (vertical)
- **Résolution** : 1080 x 1920 px
- **FPS** : 30

## Hook (1-2 secondes)

- **Durée** : 1-2 secondes MAX
- **Règle** : Impact visuel immédiat
- **Texte à l'écran** : OUI (taille 72px, position center)
- **Zoom** : Léger zoom ou mouvement de caméra
- **Son** : Musique trending ou voix claire

### Patterns de hook autorisés :
1. **Visual hook** : Image forte + texte percutant
2. **Question** : "Why..." / "How..."
3. **Statement** : "The secret to..." / "Nobody tells you..."

### Hooks interdits :
- ❌ Intro longue
- ❌ Texte trop petit
- ❌ Visage flou au début

## Cuts

- **Densité** : MOYENNE à HAUTE (cut toutes les 2-3 secondes)
- **Types autorisés** :
  - `jump_cut` : Cut net
  - `match_cut` : Cut sur un mouvement similaire
  - `transition_cut` : Cut avec transition stylée
- **Interdit** : Cut brut sans lien visuel

## Zooms

- **Activé** : OUI (plus subtil que TikTok)
- **Types** :
  - `slow_zoom` : Zoom progressif (intensity 1.1-1.2)
  - `parallax` : Effet parallaxe sur image
- **Cibles** : Visage, produit, moment clé
- **Timing** : Sur les moments importants, pas systématique

## Texte à l'écran

- **Titre** : OBLIGATOIRE (center, 72px, blanc ou noir)
- **Sous-titres** : Word-by-word (bottom, 36px)
- **Hashtags** : Dans la description
- **Animations** : `fade_in`, `slide_up`, `pop_in`

## Transitions

- **Ouverture** : Fade in ou hard cut
- **Internes** : Transitions stylées (swipe, zoom, glitch)
- **Fermeture** : Fade out ou loop

## Énergie

- **Courbe** : Hook 100% → Build 70% → Moment clé 100% → Outro 60%
- **Rythme** : Modéré à rapide
- **Son** : Musique trending, beats doux

## Aesthetic

- **Style** : Plus "clean" et "aesthetic" que TikTok
- **Couleurs** : Tons pastel ou contrastés
- **Filtres** : Légers, pas trop de glitch
- **Texte** : Police élégante, taille lisible

## Compliance

- **Disclosure** : #ad ou "Paid partnership" (si sponsorisé)
- **Copyright** : Fair use, attention aux musiques
- **Soumission** : 1-2 Reels par jour

---

*"Instagram Reels = le visual hook + l'esthétique. TikTok = le shock + la vitesse."*
