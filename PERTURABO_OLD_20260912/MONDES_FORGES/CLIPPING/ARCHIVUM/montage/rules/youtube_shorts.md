# 🎬 Règles de Montage — YouTube Shorts

> *Le fer qui veille connaît chaque faille de la fortification.*

## Format

- **Durée max** : 60 secondes
- **Aspect ratio** : 9:16 (vertical)
- **Résolution** : 1080 x 1920 px
- **FPS** : 30 ou 60

## Hook (3 premières secondes)

- **Durée** : 2-3 secondes MAX
- **Règle** : Le spectateur doit comprendre immédiatement de quoi parle la vidéo
- **Texte à l'écran** : OUI (taille 72px minimum, position center)
- **Zoom** : Léger zoom sur le visage au début
- **Son** : Pas de musique au début — voix claire

### Patterns de hook autorisés :
1. **Question** : "Wait, what?" / "You won't believe..."
2. **Statement** : "This changed everything" / "Nobody talks about..."
3. **Cliffhanger** : "Watch until the end" / "The ending though..."

### Hooks interdits :
- ❌ "Hey guys, welcome back"
- ❌ "So today we're going to talk about..."
- ❌ Trop de contexte avant le moment clé

## Cuts

- **Densité** : HAUTE (cut toutes les 2-3 secondes)
- **Types autorisés** :
  - `jump_cut` : Cut net entre deux phrases
  - `subtle_cut` : Micro-cut pour enlever les pauses
- **Interdit** : Cut sur un mot en cours

## Zooms

- **Activé** : OUI
- **Types** :
  - `slow_zoom` : Zoom progressif (intensity 1.2-1.3)
  - `dramatic_zoom` : Zoom rapide sur moment choquant (intensity 1.5)
- **Cibles** : Visage principalement
- **Timing** : Sur les moments clés (punchline, émotion forte)

## Texte à l'écran

- **Titre** : OBLIGATOIRE (top center, 64px, rouge ou blanc)
- **Sous-titres** : Word-by-word (bottom, 36px, blanc)
- **Hashtags** : Bottom right, 24px, gris
- **Animations** : `pop_in`, `fade_in`, `typewriter`

## Transitions

- **Ouverture** : Hard cut depuis noir
- **Internes** : Cut simple (pas de transitions fancy)
- **Fermeture** : Fade to black (0.5s)

## Énergie

- **Courbe** : Hook 100% → Build 70% → Punchline 100% → Outro 50%
- **Rythme** : Rapide, pas de temps morts
- **Son** : Pas de musique fond, focus voix

## Compliance

- **Disclosure** : #ad (si sponsorisé)
- **Copyright** : Fair use Section 107
- **Soumission** : < 1h après publication
