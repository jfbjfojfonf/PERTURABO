# _PIEGES_APPRIS — Mode PUR
> Les leçons du mode PUR — **à lire avant chaque siège**.
---
## 🚫 Les erreurs à ne PAS reproduire
### 1. B-roll sur le hook
**Erreur** : Placer un B-roll dans les 3 premières secondes.
**Pourquoi c'est mal** : Le hook doit montrer le visage du speaker pour créer une connexion émotionnelle.
**Correction** : Hook pur (0-3s) = visage speaker, pas de B-roll.
### 2. B-roll sur l'emotion_peak
**Erreur** : Placer un B-roll pendant le moment le plus intense.
**Pourquoi c'est mal** : Le viewer a besoin de voir la réaction du speaker.
**Correction** : Scorer les segments — emotion_peak = score bas = pas de B-roll.
### 3. Trop de B-roll
**Erreur** : 5 B-roll pour un clip de 15 secondes.
**Pourquoi c'est mal** = Le viewer perd le fil, ça devient un slide show.
**Correction** : Respecter les duration_rules (15s→1, 30s→3, etc.)
### 4. Pas d'anti-detection
**Erreur** : Publier le clip tel quel sans traitement.
**Pourquoi c'est mal** : Les plateformes détectent la duplication et ban.
**Correction** : Au minimum mirror + 1 SFX.
### 5. Hook avec texte à l'écran
**Erreur** : Afficher du texte pendant le hook.
**Pourquoi c'est mal** : Le hook doit être visuel (visage speaker), pas textuel.
**Correction** : Le titre arrive APRÈS le hook (à la 3e seconde).
### 6. Clip trop court
**Erreur** : Clip de 5 secondes.
**Pourquoi c'est mal** : Watch time trop faible, l'algorithm pénalise.
**Correction** : Minimum 10 secondes, sweet spot 20-40 secondes.
### 7. Clip trop long
**Erreur** : Clip de 90 secondes (sauf ranking).
**Pourquoi c'est mal** : Le viewer décroche, watch time % faible.
**Correction** : Maximum 60 secondes (sauf ranking qui peut aller à 120s).
### 8. B-roll sans rapport
**Erreur** : B-roll générique qui n'a rien à voir avec le contenu.
**Pourquoi c'est mal** : Le viewer est confus, ça casse l'immersion.
**Correction** : B-roll doit TOUJOURS illustrer ce qui est dit.
### 9. SFX trop forts
**Erreur** : SFX au même volume que la voix.
**Pourquoi c'ést mal** : Ça écrase le dialogue, c'est agressif.
**Correction** : SFX entre -15 et -20dB, toujours en dessous de la voix.
### 10. Oublier le scoring B-roll
**Erreur** : Placer les B-roll au hasard.
**Pourquoi c'est mal** : Les meilleurs moments ne reçoivent pas de B-roll.
**Correction** : TOUJOURS scorer avant de placer.
---
## ✅ Les bonnes pratiques
1. **Toujours commencer par le scoring** — ne jamais placer de B-roll au hasard
2. **Hook pur** — visage speaker, pas de texte, pas de B-roll
3. **Anti-detection systématique** — mirror + zoom + 1 SFX minimum
4. **B-roll en rapport** — toujours illustrer ce qui est dit
5. **SFX subtils** — en dessous de la voix
6. **Zoom invisible** — le viewer ne doit jamais le remarquer
7. **Valider chaque gate** — ne jamais sauter une validation
8. **Vérifier le production_pack** — tout doit être cohérent avant export
