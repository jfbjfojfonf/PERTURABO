# Prototype STAND UP

Ce dossier conserve le prototype non déployé du mode STAND UP. Il transforme un transcript, un tweet ou un post Reddit fourni par l’opérateur en sujets de réaction ; il ne lance aucun rendu et ne constitue pas un workflow HERESIE actif.

Le moteur et le fragment de workflow sont conservés comme matériel de conception. Toute future activation devra être décidée séparément.
