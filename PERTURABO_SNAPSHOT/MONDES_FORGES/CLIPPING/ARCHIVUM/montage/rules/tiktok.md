# 🎬 Règles de Montage — TikTok

> *Le fer qui veille connaît chaque faille de la fortification.*

## Format

- **Durée** : 15-60 secondes (optimal : 30-45s)
- **Aspect ratio** : 9:16 (vertical)
- **Résolution** : 1080 x 1920 px
- **FPS** : 30

## Hook (2 premières secondes)

- **Durée** : 1-2 secondes MAX (plus rapide que YouTube)
- **Règle** : Le spectateur doit être ACCROCHÉ avant la première seconde
- **Texte à l'écran** : OUI (taille 80px minimum, position center)
- **Zoom** : Zoom rapide sur le visage
- **Son** : Utiliser les sounds trending si possible

### Patterns de hook autorisés :
1. **Shock** : "I can't believe..." / "This is insane..."
2. **Question** : "Did you know..." / "Why does nobody..."
3. **Statement** : "The truth is..." / "Here's what they don't tell you..."

### Hooks interdits :
- ❌ Intro longue
- ❌ "Hey guys"
- ❌ Contexte avant le moment clé

## Cuts

- **Densité** : TRÈS HAUTE (cut toutes les 1-2 secondes)
- **Types autorisés** :
  - `jump_cut` : Cut net (le plus utilisé sur TikTok)
  - `smash_cut` : Cut brutal avec changement d'angle
- **Interdit** : Cut lent, transitions douces

## Zooms

- **Activé** : OUI
- **Types** :
  - `dramatic_zoom` : Zoom rapide et intense (intensity 1.6-2.0)
  - `face_zoom` : Zoom sur le visage (intensity 1.4)
- **Cibles** : Visage, mains, objets importants
- **Timing** : Sur chaque punchline

## Texte à l'écran

- **Titre** : OBLIGATOIRE (center, 80px, couleur vive)
- **Sous-titres** : Word-by-word avec couleur (bottom, 40px)
- **Hashtags** : Dans la description, pas sur la vidéo
- **Animations** : `pop_in`, `shake`, `glitch`

## Transitions

- **Ouverture** : Hard cut ou smash cut
- **Internes** : Cut simple, parfois avec flash
- **Fermeture** : Loop (la fin reboucle sur le début)

## Énergie

- **Courbe** : Hook 100% → Build 60% → Punchline 100% → Loop
- **Rythme** : TRÈS rapide, aucun temps mort
- **Son** : Utiliser les sounds trending, beats synchronisés avec les cuts

## Trends & Sounds

- **Priorité** : Utiliser les sounds trending quand pertinent
- **Hashtags** : #fyp #foryou #viral + hashtags niche
- **Posting** : 1-3 vidéos par jour optimal

## Compliance

- **Disclosure** : #ad (si sponsorisé)
- **Copyright** : Fair use, mais attention aux sounds
- **Soumission** : Immédiate (TikTok = instantanéité)
