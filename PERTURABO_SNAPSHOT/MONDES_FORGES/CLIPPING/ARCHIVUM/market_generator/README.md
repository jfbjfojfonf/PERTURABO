## Structure attendue d'un profil marché

Chaque `<market>_profile.md` contient :

1. **Langue** : langue principale (english, français, etc.) + variantes régionales
2. **Slang** : mots qui ont phase (vivants) + mots morts (obsolètes, à éviter) — voir aussi `copywriting/slang_by_market.md`
3. **Références culturelles** : événements récents, créateurs phares du marché, memes viables
4. **Pacing culturel** : tempo de discourse attendu (US jeune = punch direct + rapide, FR adulte = plus posé, etc.)
5. **Music trends** : genres écoutés, upbeat vs lofi, audio trends
6. **Thumbnail text / hook texte** : style d'écriture typique (capitals, abréviations, emojis)
7. **Hashtags typiques** : large + moyen + niche — voir `copywriting/hashtags_research.md`
8. **Horaires de post optimaux** : fuseau horaire + heures de pic d'audience (EST/Los Angeles/Tokyo/etc.)
9. **Mots/terms à éviter** : shadowban terms 리스트 (TikTok notamment)
10. **Valeurs dominantes** : ce qui active l'audience (achievement, anti-complacency, hustle, sarcasm, etc.)

## Couplage avec copywriting/

Le profil marché est couplé à `ARCHIVUM/copywriting/slang_by_market.md`. Le profil marché est l'info statique (qui est l'audience), le slang_by_market est la tactique copywriting (comment leur parler).
